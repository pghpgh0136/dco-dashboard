Mermaid Engine

이 대시보드는 Frontend (HTML/JS), 경량 백엔드 (Python HTTPServer), 그리고 Google Gemini API (LLM)가 유기적으로 연동되어 작동합니다.

🖥️ Frontend (UI)
• 수료 잔여 시간 실시간 계산
• 오늘의 강의실 & 시간표 렌더링
• 비동기(Fetch) AI 챗봇 인터페이스
⚙️ Backend Server
• Python server.py 경량 프록시
• /api/chat 엔드포인트 보안 중계
• 503 오류 시 Gemini 모델 다중 Failover
☁️ Gemini AI Cloud
• 시니어 DCO 엔지니어 페르소나 주입
• gemini-3.1-flash-lite 기본
• 데이터센터 실무 지식/퀴즈 생성
🌐 시스템 상호작용 구성도

sequenceDiagram
    autonumber
    actor User as 사용자

    User->>UI: 질문 입력 및 전송

    alt 정상 응답

    end
