⚙️ 시스템 아키텍처 & 동작 원리 시각화
Mermaid Engine

이 대시보드는 Frontend (HTML/CSS/JS), Render 백엔드 (Python server.py), Supabase (PostgreSQL Database), 그리고 Google Gemini API (LLM)가 유기적으로 연동된 현대적인 클라우드 아키텍처로 작동합니다.

🖥️ Frontend (index.html)
• 실시간 오늘/주차별 시간표 및 진도율 렌더링
• 메모/퀴즈/지식카드 및 관리자 대시보드 UI
• AI 비서 Tool Calling 명령 비동기 수신/실행
⚙️ Backend Server (Render)
• Python 표준 HTTP & REST API 게이트웨이
• PBKDF2-HMAC-SHA256 보안 인증 & 세션 토큰
• 1일 5회 호출 제한 및 관리자 활동 로깅
🗄️ Database (Supabase)
• PostgreSQL 기반 7개 핵심 테이블 관리
• service_role 키 전용 PostgREST 격리 보안
• 계정별 메모·퀴즈·지식카드·대화로그 영구 보존
☁️ Gemini AI Cloud
• 시니어 DCO 엔지니어 전문 페르소나 탑재
• Function Calling 기반 웹 기능 제어 툴 연동
• gemini-3.1-flash-lite 초고속 실무 질의응답

🔄 시스템 상호작용 시퀀스 
sequenceDiagram
    autonumber
    actor User as 👤 사용자
    participant UI as 🖥️ 브라우저 (JS)
    participant Server as ⚙️ Render (server.py)
    participant DB as 🗄️ Supabase DB
    participant AI as ☁️ Gemini API

    Note over User,DB: [1] 회원가입 & PBKDF2 로그인 인증
    User->>UI: 로그인 요청 (ID/비밀번호)
    UI->>Server: POST /api/auth/login
    Server->>DB: user_accounts 조회 (service_role)
    DB-->>Server: 계정 정보 & password_hash
    Server->>Server: PBKDF2 암호화 검증 & 세션토큰 발급
    Server->>DB: session_token 갱신 저장
    Server-->>UI: { token, user: { role, daily_limit } }

    Note over User,DB: [2] 사용자 데이터 저장 & 복원 (메모/퀴즈/카드)
    User->>UI: 메모 작성 또는 퀴즈/카드 생성
    UI->>Server: POST /api/user/save-data { type, items }
    Server->>DB: user_memos / quizzes / cards 동기화
    DB-->>Server: 201 Created / 저장 성공
    Server-->>UI: { success: true }
    UI->>Server: GET /api/user/data (새로고침 시)
    Server->>DB: 사용자별 격리 테이블 조회
    DB-->>Server: JSONB 데이터 반환
    Server-->>UI: { memos, cards, quizzes, chat }

    Note over User,AI: [3] AI 질문 & 자연어 웹 기능 실행 (Tool Calling)
    User->>UI: "오늘 시간표 보여줘" 입력
    UI->>Server: POST /api/chat { message }
    Server->>DB: api_daily_usage 조회 & 5회 한도 체크
    Server->>AI: generateContent (DCO 페르소나 + Web Tools)
    alt 일반 기술 질문
        AI-->>Server: 텍스트 답변 반환
        Server->>DB: user_chat_logs 대화 저장
        Server-->>UI: { type: "text", reply: "..." }
        UI->>User: 챗봇 말풍선 답변 출력
    else 웹 기능 제어 (Function Call)
        AI-->>Server: functionCall: show_today_schedule
        Server-->>UI: { type: "function_call", function_call: {...} }
        UI->>UI: JS 기존 함수 직접 호출 (시간표 표시)
        UI->>User: "오늘 시간표를 표시했습니다" 안내
    end
